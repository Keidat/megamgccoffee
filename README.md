# 메가 레시피 노트

빌드나 서버 API가 필요 없는 GitHub Pages용 정적 페이지입니다. `index.html`을 직접 열어서도 사용할 수 있습니다.

## 수록 범위

사용자가 현행임을 확인한 PDF와 공식 메뉴 대조표에서 연결된 112개 HOT/ICE 제조 항목입니다. 미확보 디저트, 비공식 재현, 원문 명칭·재료가 불일치하는 #107, 별도 꿀팁옵션은 제외했습니다. PDF의 단위와 수치는 보존하며 원문에서 생략된 값은 추정하지 않습니다.

## GitHub Pages 배포

이 폴더의 `index.html`, `style.css`, `app.js`, `search.js`, `data.js`, `source.pdf`, `.nojekyll`을 저장소 루트 또는 `docs/`에 올립니다. 저장소 Settings → Pages → Deploy from a branch에서 해당 브랜치와 폴더를 선택합니다. 모든 파일 경로가 상대경로라 저장소 하위 주소에서도 동작합니다.

현재 GitHub 배포는 실행하지 않았습니다.

## 추가 조사 메뉴

2026-11-06: 총 99개 메뉴 / 128개 온도별 항목입니다. PDF 112개와 비공식 추가 자료 16개로 구성됩니다. 추가 자료에는 계량이 불완전한 암기자료와 영상에서 확인한 부분 공정이 포함됩니다. 목록과 상세 화면에 누락 정보와 출처를 표시하며 완전한 제조법으로 분류하지 않습니다. `supplemental.json`에서 관리합니다.

## 갱신 및 확인

`prepare.py`는 상위 `output/megacoffee/recipes.json`에서 공개할 데이터를 생성하고 PDF를 복사합니다. 데이터 변경 후 Python으로 실행합니다. `node test.cjs`로 검색 및 수록 범위를 검사할 수 있습니다. `data.js`의 메뉴 `aliases`에 검색 별칭을 추가할 수 있습니다. 실제 제조 데이터가 없는 메뉴를 검색용 가짜 레시피로 추가하지 않습니다.
